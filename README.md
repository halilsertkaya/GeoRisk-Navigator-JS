# 🌍 GeoRisk-Navigator (JS Edition)

An interactive, serverless Web-GIS application designed to map and analyze earthquake and landslide hazard zones using **Leaflet.js**, **Bootstrap 5**, and browser **LocalStorage**.

🔗 **Live Demo:** [View Live on GitHub Pages](https://halilsertkaya.github.io/GeoRisk-Navigator-JS/)  
*(Replace `YOUR_USERNAME` with your actual GitHub username after publishing)*

---

## ✨ Features
* **Zero Backend Required:** Runs entirely on the client-side (HTML5/JavaScript) with no need for PHP, MySQL, or PostgreSQL setup.
* **Interactive Leaflet Map:** Pan, zoom, and explore risk zones dynamically.
* **Point-and-Click Addition:** Click anywhere on the map to automatically capture coordinates and add custom hazard points.
* **Risk Categorization:** Color-coded markers (Green for Low, Yellow for Medium, Red for High) with detailed popup descriptions.
* **Persistent Storage:** Uses browser `LocalStorage` to save your added markers locally across sessions.

---

## 🚀 How to Run Locally
1. Clone or download this repository.
2. Open the `index.html` file in any modern web browser (Chrome, Firefox, Edge, Safari). No local server needed!
